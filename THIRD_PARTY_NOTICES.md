# Third-party notices for the public demo

This file covers the Python packages installed for the public sample demo.
It does not cover the separate local prototype. PyMuPDF and the OpenAI Python
SDK are not part of this demo dependency set. Leaving them out of the demo
does not decide the license questions for distributing the local PDF
implementation.

The direct requirements are pinned in `requirements-demo.txt`.
`requirements-demo.lock` records the transitive set resolved from those pins
on 2 November 2026. It was not copied from the developer virtualenv.

No license has been selected for the original InvoiceFlow code. That choice
belongs to the repository owner.
